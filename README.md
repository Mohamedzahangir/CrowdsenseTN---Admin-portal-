# 🚦 CrowdSense TN – Admin Portal

CrowdSense TN Admin Portal is a centralized transportation operations platform designed to monitor, manage, and optimize public transit systems through real-time operational intelligence.

## 🌐 Live Demo

https://crowdsense-tn-admin-portal-tn.vercel.app

---

# Overview

The Admin Portal acts as the command center of the CrowdSense TN ecosystem.

Transport authorities and operators can:

* Monitor active buses
* Manage routes and stops
* Track occupancy levels
* Supervise IoT devices
* Monitor GPS locations
* Analyze transportation trends
* Configure operational settings
* Manage alerts and notifications

The portal provides a complete overview of the transportation network from a single interface.
